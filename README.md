# Anime Face Generation using Generative Adversial Network (GAN)

A Generative Adversarial Network (GAN) is a machine learning framework where two neural networks compete against each other to create realistic synthetic data.
A GAN consists of two main parts: \
**Generator:** This network takes random noise as input and creates fake data, such as images, audio, or text. **Discriminator: **This network acts as a detective. It evaluates data and tries to determine whether it is real (from the training dataset) or fake (created by the generator) \

In this project, new Anime faces were generated using Generative Adversial Network (GAN). The model was trained on Anime Face Dataset (source:Kaggle) and new Anime Faces images close to Real Anime Face images were generated using Generator model. Then, Discriminator model was used to distinguish between Real Anime faces images and Fake Anime face images (generated by Generator model) which the Discriminator model failed to recognise presuming it to be real Anime face images.

## **Dataset Description:**

The dataset(Source: Kaggle) used in this project is often used for generating anime waifus!.

But, suppose instead of training the Deep Convolutional Generative Adversial Network (DCGAN)for 50 epochs, if the DCGAN was trained for more no. of epochs (For instance 100 epochs) then, we would have achieved much better Real, Fake and Discriminator Accuracy and would have obtained much better Generator results. (Generator would
have generated much better Anime Fake Face Images). \
The Real Anime face image accuracy obtained using DCGAN was 0.5, Fake Anime Face image accuracy was 0.96875 and the discriminator accuracy obtained was 0.734375. The accuracy obtained was 0.5 which was too low, but if the DCGAN would have been trained for more no. of epochs, the accuracy obtained would have been much higher. \
