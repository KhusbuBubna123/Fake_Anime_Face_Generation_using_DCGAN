A GAN consists of two main parts: \
**The Generator:** This network takes random noise as input and creates fake data, like a forged painting. \
**The Discriminator: **This network acts as an expert detective. It looks at real data from a training set and fake data from the generator, and tries to guess which is which. Both networks train together in a game. As the discriminator gets better at spotting fakes, the generator learns to make more realistic data. The goal is for the generator to create data so convincing that the discriminator can no longer tell it apart from real data. \

In this project, new Anime faces were generated using Generative Adversial Network (GAN). The model was trained on Anime Face Dataset (source:Kaggle) and new Anime Faces images close to Fake Anime Face images were generated using Generator model. Then, Discriminator model was used to distinguish between real Anime faces images and fake Anime face images(generated by Generator model) which the Discriminator model failed to recognise presuming it to be real Anime face images.
