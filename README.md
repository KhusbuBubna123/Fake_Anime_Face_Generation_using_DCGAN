A GAN consists of two main parts: \
**Generator:** This network takes random noise as input and creates fake data, such as images, audio, or text. **Discriminator: **This network acts as a detective. It evaluates data and tries to determine whether it is real (from the training dataset) or fake (created by the generator) \

In this project, new Anime faces were generated using Generative Adversial Network (GAN). The model was trained on Anime Face Dataset (source:Kaggle) and new Anime Faces images close to Real Anime Face images were generated using Generator model. Then, Discriminator model was used to distinguish between Real Anime faces images and Fake Anime face images (generated by Generator model) which the Discriminator model failed to recognise presuming it to be real Anime face images.

## **Dataset Description:**

The dataset used in this project is often used for generating anime waifus! (Source:Kaggle).

This dataset has **63,632** "high-quality" anime faces… but let's be real… all anime girls are high-quality
anime girls.
