# GAN Anime Face Generation
In this project, new Anime faces were generated using Generative Adversial Network(GAN). The model was trained on Anime Face Dataset (source:Kaggle) and new Anime Faces images close to Fake images were generated using Generator model. Then Discriminator model was used to distinguish between real anime faces and fake anime images(generated by Generator model) which the Discriminator model failed to recorgnize presuming it to be real anime face images.

**Dataset Description:**

This dataset is often used for varying projects with anime faces. I will keep this dataset up-to-date and clean, along with including fun scripts for generating anime waifus! (Source:Kaggle).
